# Portfolio de Francisco Sucatti

Mi sitio personal, con mis proyectos, quién soy y cómo contactarme.

**Hecho con:** [Astro](https://astro.build), TypeScript, Tailwind CSS y Three.js.

## Probarlo en tu computadora

Necesitás Node.js 22 o superior.

```bash
npm install
```

```bash
cp .env.example .env
```

```bash
npm run dev
```

Abre <http://localhost:4321>. Sin los datos de EmailJS en `.env`, el sitio funciona igual y el formulario le pide al visitante que escriba por email.

## Comandos

| Comando | Qué hace |
|---|---|
| `npm run dev` | Servidor de desarrollo con recarga automática |
| `npm run build` | Genera el sitio final en `dist/` |
| `npm test` | Pruebas en el navegador. En Windows usan Microsoft Edge |
